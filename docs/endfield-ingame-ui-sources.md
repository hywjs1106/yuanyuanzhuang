## 官方交互与信息组织事实

以下是官方文章明确描述的行为；没有从静态图推断动画、触摸手感或实际性能。

- **任务接通下一步。** 在任务页面开始追踪后，消息步骤直接进入对应 BAKER，地点步骤直接打开地图并锁定目标；地图标记详情还可选中最近的传送点。带角标任务的优先级为新功能、新区域、重要剧情、限时。[2026-07-16「向渊行」更新说明](https://endfield.hypergryph.com/news/9335)
- **重叠对象可消歧，前置条件可跳转。** 俯瞰模式选中重叠设备会提供选项列表；工业节点的前置任务旁有跳转按钮，已接任务进入任务页面，未接任务显示提示。[2026-07-11「向渊行」研发通讯](https://endfield.hypergryph.com/news/7219)
- **干员展示有独立查看用途。** 干员展示界面允许切换查看已拥有干员的 2D 立绘。[2026-07-16 更新说明](https://endfield.hypergryph.com/news/9335)
- **数量限制及时显露。** 蓝图框选超出上限时实时显示已选数量和可保存上限，可调整已有范围，免于重新框选。[2026-08-22「雪凇幽梦」研发通讯](https://endfield.hypergryph.com/news/4776)
- **浏览进度驱动页签。** 蚀刻章分类页签随浏览进度自动切换；好友列表扩大名片背景的显示范围。[同一官方研发通讯](https://endfield.hypergryph.com/news/4776)
- **减少页面往返与重复加载。** 战争回响的难度选择界面可直接切换关卡；战争回响和影拓丰碑通关后返回关卡列表不再触发加载。[同一官方研发通讯](https://endfield.hypergryph.com/news/4776)
- **养成总览集中目标与资源。** 干员中的培养总览展示已拥有、未拥有、前瞻干员及武器，比较目标所需资源与当前库存。[2026-09-02「雪凇幽梦」更新说明](https://endfield.hypergryph.com/news/2653)

这些条目说明官方同时处理视觉信息、导航关系、状态反馈和操作连贯性；“黑白黄”本身不能概括完整的游戏内 UI。
