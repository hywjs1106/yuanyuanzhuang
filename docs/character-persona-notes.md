# 庄方宜角色风格：来源与实现边界

这是原创角色演绎适配，不是官方对话、声音或人物形象资源。聊天页用文字身份标识；未接入模型时明确显示「离线预设」，只能进行有限的分类回复和简单流水识别。

## 已核实的资料

- [干员资料及语音整理](https://warfarin.wiki/cn/operators/zhuang-fangyi)：武陵科学发展区管代、研究与天师背景；沉着博学，待人温和，重视职责与日常生活。由此改编自然、温柔而有判断力的说话方式。资料来自社区整理，不等同官方背书。
- [大器晚成](https://warfarin.wiki/cn/missions/e10m2)：共同推演技术问题，冒险考虑试验风险和范围；接受分工、关心受伤同伴。改编为具体讨论、清楚判断、关心通过行动表达的风格。
- [志同道合](https://warfarin.wiki/cn/missions/e10m4)：学校与广场承接日常愿望；给年轻时的自己留出悲伤空间，关心管理员疲惫并邀请散步。改编为允许休息、克制陪伴，不强迫励志或制造恋爱关系。
- [BWiki 人物档案](https://wiki.biligame.com/zmd/庄方宜)：用于交叉核对角色资料。未在应用中复制完整档案或受保护对白。

上述剧情是团队研究核实的社区逐句转录；对话顺序、分支归属仍有整理不确定性，不将分支合并成一段官方对话。用户给出的 fz.wiki 页面只取得客户端外壳，没有声称已完整阅读原站第二章。

## 实现

`persona.ts` 的提示和所有示例回复均为原创适配：默认称呼管理员，用户提出偏好时模型遵从；通常一至三小段，适量含蓄幽默，不把每次闲聊变成任务。普通聊天返回空动作；记账、提醒和备忘仍需明确请求和逐项确认。

不声称实际看见用户、读心、泡茶、通知他人、播放角色声音；不捏造共同经历、剧情细节或实时天气。用户问身份时明确为终端中的角色演绎。

离线回复是规则预设，不具有模型级的上下文理解或完整角色扮演能力；页面与回复如实说明限制。设置齐全时使用既有 AI 传输、权限和解析验证，发送二十条最近的用户/助手消息；屏蔽历史里的 system 角色，终端上下文以数据消息提供。停止或切页会取消请求并屏蔽晚到回复。

测试验证真实发出的消息、普通聊天零动作、离线闲聊分流、确认式流水提案、非法动作拒绝、中止和界面状态。测试传输桩只能证明请求与解析契约；不同用户所选模型的实际风格质量仍取决于模型遵从程度。
