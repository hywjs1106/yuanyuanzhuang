# 助手页：人物互动预览

2026-10-15，用户选择保留聊天记录并增加人物表情、回复动效和小互动。

- `FangyiPresence` 是独立的本地表现组件。点击头像轮换目录中的招呼、微笑、点赞表情；五秒后恢复，可再点停止。后台、离开视口或切页时清理；开启减少动态效果时只用静态预览。加载失败回到头像，不在这里请求外部表情 URL。
- 请求中的人物状态直接来自既有 `busy`，使用静态思考图，不把它说成联网或真实心理活动。没有增加模型调用、语音、长期记忆或聊天记录。
- 空白会话的三个话题只填草稿并聚焦输入框，不自动发送，不覆盖非空内容。已有消息时不显示。
- 新回复的文字立即完整显示，边缘提示只播放600ms；历史消息不重播，减少动态效果时不播放。原有新表情五秒播放和历史静态预览机制保留。
- 空白会话从顶部开始；已有历史仍按阅读位置决定是否滚到底部，并保留「最新消息」。短屏压缩人物区、隐藏功能提示；键盘态使用更小头像。
- 原人格提示、动作协议、操作校验、真实回执、数据库和原生工程未改。未生成APK；仍须用户明确同意才能打包。

预览：工作区 `references/ui-20/companion-preview.webm`。演示使用临时浏览器会话与离线预设回复，不代表已接入用户的真实API。

验证：91项Node测试、50项浏览器测试；随后修复短屏和减少动态效果细节，并通过7项相关回归。独立只读复查确认360×640、375×667、320×568、320×740初始完整问候和首次发送滚动正常。浏览器模拟不等于Android真机IME/性能验证。
