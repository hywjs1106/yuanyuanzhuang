# 日常终端0.6 UI改版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用户进入首页能看到实时钟表和明显的等高线流动，四个精细入口位于圆外四角，全APP界面采用统一的终末地工业通讯设计。
**Architecture:** 只调整React/CSS表现层；新增独立LiveClock组件，保留OverviewPanel导航与账目真实数据。共享图标与全局皮肤独立于通知、数据库和AI动作。
**Tech Stack:** existing React/Capacitor/CSS/SVG, local Noto SC.
**Spec:** PRODUCT.md及用户本轮具体反馈。

## Constraints
- 公历日期在标题，不放回圆心；圆心显示真实HH:mm:ss，秒针据设备时间更新，圆不是定位地图。
- 四个>=48px功能入口在圆外四角，禁止与圆或图标内容重叠。320/390/414宽度和增大字号均要正常。
- 等高线通过可见线条位移/流动表现；减少动态时不播放，时间文本仍保持真实。
- 不改数据库/AI保存规则/表情资源/提醒原生行为；保留底部导航/AndroidBack/IME。
- 始终功能可用，动画不延迟操作；所有动效可减少；无新远程字体/图片。
